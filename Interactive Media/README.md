# Interactive Media & Creative Coding

Creative computing explorations and visual interactions developed using JavaScript and the [p5.js](https://p5js.org/) creative coding library.

## Projects

### 1. Interactive Self-Portrait
> **Path**: [`Self-portrait/`](./Self-portrait)

An expressive graphical self-portrait rendered dynamically on an HTML5 canvas. Combines geometric shapes, custom bezier curves, and color palettes that react to user inputs.

- **To run**: Open `Self-portrait/index.html` in any modern web browser or serve locally with `npx serve Self-portrait`.
