# Operating Systems (CS 202)

Study and practical lab explorations in systems programming, OS architecture, concurrency, and resource virtualization at New York University.

## Core Topics & Lab Focus Areas

- **Concurrency & Synchronization**: Threads, race conditions, mutual exclusion locks, condition variables, semaphores, and deadlock prevention.
- **Process Management & Scheduling**: Process creation (`fork`, `exec`, `wait`), context switching, preemptive CPU scheduling algorithms, and IPC (Inter-Process Communication).
- **Virtual Memory Architecture**: Paging mechanisms, multi-level page tables, translation lookaside buffers (TLB), virtual-to-physical address translation, and page replacement policies (LRU).
- **File Systems & Storage**: Inodes, directories, file descriptors, storage allocation techniques, caching layers, and crash consistency (journaling).
- **Security & Protection**: Kernel vs. user mode transitions, system calls, hardware protection rings, and privilege isolation.
