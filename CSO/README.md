# Computer Systems Organization (CSO)

Low-level systems programming exercises, assignments, and architectural exploration in C, completed for the Computer Systems Organization course at NYU Tandon.

## Key Topics Covered

- **Bitwise Operations & Data Representation**: Integer arithmetic, two's complement representation, IEEE 754 floating-point mechanics, bitmasking, and bit-level shifts.
- **Pointers & Memory Architecture**: Dynamic heap allocation (`malloc`, `calloc`, `free`), pointer arithmetic, stack frames, buffer boundaries, and manual memory leak debugging.
- **Assembly Concepts & Machine Code**: Linking, disassembly, and understanding how high-level C constructs translate into machine instructions.
- **Modular C Development**: Multi-file compilation, header organization, makefiles, and compiler optimization flags.

## Directory Layout

- `HW1/`: Integer conversions, bit-level problem solving, and arithmetic implementations.
- `HW2/`: Systems exercises and data manipulation tasks.
- `Recitations/`: Weekly hands-on lab problems covering pointer manipulation, struct layout, and string parsing in C.
