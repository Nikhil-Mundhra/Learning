# Gamified Learning — Educational Game Design

Projects and prototypes exploring how interactive gameplay mechanics and gamification can improve learning outcomes, retention, and social awareness.

## Featured Project: SmogLife

> **Path**: [`SmogLife GameMaker/`](./SmogLife%20GameMaker)

**SmogLife** is an interactive 2D narrative game built in GameMaker Studio. The player navigates an urban environment combating air pollution challenges through puzzles and active decision-making.

### Key Highlights
- **Game Engine**: GameMaker Studio (GML scripting).
- **Architecture**: Object-oriented event loops controlling player movement, interactive environmental triggers, collision detection, and level transitions.
- **Asset Pipeline**: Custom animated sprites with directional character states (idle, walk directions, win/lose states), custom sound design, and atmospheric audio cues.
- **Pedagogical Design**: Translates complex environmental science concepts into approachable game rules and win/loss feedback loops.
